# Ananya G. Shetty — Full Stack Developer Portfolio

A warm, modern, fully responsive personal portfolio website built with **HTML, CSS, and vanilla JavaScript**. It showcases my education, skills, projects, certificates, and contact details — with a light/dark theme and an interactive certificate viewer.

🔗 **Live Demo:** _add your deployed link here_

---

## ✨ Features

- 🎨 **Warm burgundy / cream theme** with a matching dark mode (saved to `localStorage`)
- 📱 **Fully responsive** — works on desktop, tablet, and mobile
- 🖼️ **Certificate viewer** — click any certificate to open it in a full-screen popup
- 📜 **Resume button** — view/download resume directly from the hero
- 🎯 **Scroll-based nav highlighting** using the Intersection Observer API
- 🌟 **Reveal-on-scroll animations** and subtle cursor glow effect
- 🧭 Smooth scrolling and clean, accessible markup

---

## 🛠️ Tech Stack

- **HTML5** — semantic structure
- **CSS3** — custom properties, grid, flexbox, animations
- **JavaScript (Vanilla)** — theme toggle, modal, scroll effects
- **Font Awesome** — icons
- **Google Fonts** — Playfair Display & DM Sans

## 🚀 Getting Started

### Run locally

1. Clone the repository
   git clone https://github.com/Ananya-G-Shetty/your-repo-name.git

2. Open the folder
    cd your-repo-name

3. Launch the site

Simply open index.html in your browser, or
Use the Live Server extension in VS Code for auto-reload.


🎨 Customization
Colors: edit the CSS variables in :root (and body.dark) inside style.css
Content: update text, projects, and certificates directly in index.html
Images / Resume: add or replace files inside the assets/ folder
Links: update your GitHub, LinkedIn, and email links in the hero and contact sections
